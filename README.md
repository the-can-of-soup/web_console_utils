# Soup's JS Console Utils for the Web

Userscript adding miscellaneous helpful JS utilities for browser consoles, especially for reverse-engineering and debugging.

To install, use a userscript manager such as [Tampermonkey](https://tampermonkey.net/).<br>
**URL for installation: [`https://github.com/the-can-of-soup/web_console_utils/raw/refs/heads/main/soup_console_utils.user.js`](https://github.com/the-can-of-soup/web_console_utils/raw/refs/heads/main/soup_console_utils.user.js)**

All utilities are made available in the `soupConsoleUtils` object. Their usage is documented in code comments.

> [!NOTE]
>
> These utilities are meant for manual use in the console, so breaking changes may be made at any time.
